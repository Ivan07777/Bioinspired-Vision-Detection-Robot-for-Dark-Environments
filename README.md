# UWE - Final Year Project

Uni Project - Bioinspired Vision Detection Robot for Dark Environments

This is my final year project for the Enginnering Project module of my University at UWE where I investigate, and try to replicate to an extend the vision capabilities of a Vanadis Bristle Worms Big Eyes in relation to their heads, to vision efficiently blue light in a very dark enviroment, by mainly using an STM32 F446RE Board and a OV7670 camera
